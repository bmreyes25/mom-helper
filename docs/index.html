∑Question 4Calculus I

Find the inverse of f(x) = (8x + 9) / (10x − 2)

SOLUTION STEPS

01

Set the output equal to the function.

y = (8x + 9) / (10x − 2)
02

Multiply by the denominator.

y(10x − 2) = 8x + 9
03

Collect and factor the x terms.

x(10y − 8) = 9 + 2y
ANSWERf−1(x) = (9 + 2x) / (10x − 8)

GET STARTED

Install in Chrome

  1. Download the latest ZIP and extract it.
  2. Open chrome://extensions and turn on Developer mode.
  3. Choose Load unpacked and select the extracted extension folder.
  4. Open a supported MyOpenMath Calculus I question, then click the MOM Helper icon.

Chrome may display a developer-mode notice for unpacked extensions. The source is available in the GitHub repository.
